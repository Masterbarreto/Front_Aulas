## 🎯 Sobre o Projeto

O **SubAulas** é uma solução tecnológica desenvolvida para modernizar e otimizar o processo de substituição de aulas no ambiente educacional da EEEP Walter de Sá Cavalcante. O sistema oferece uma interface intuitiva e segura que permite aos professores cadastrar, visualizar e gerenciar aulas disponíveis para substituição de forma eficiente.

### 🔍 Problema Identificado
- Processo manual e demorado para encontrar e gerenciar aulas de substituição.
- Falta de um sistema centralizado para visualizar as aulas disponíveis por curso, ano e matéria.
- Dificuldade no controle administrativo sobre as aulas que foram aplicadas.

### 💡 Solução Proposta
Uma plataforma web centralizada que garante:
- **Agilidade** na busca e cadastro de aulas.
- **Transparência** na disponibilidade de aulas de substituição.
- **Controle** administrativo e pedagógico aprimorado.
- **Segurança** através de autenticação para gerenciamento.

---

## ⚡ Funcionalidades

### 🔐 Autenticação e Gestão
- **Login Administrativo:** Acesso seguro para professores gerenciarem as aulas.
- **Dashboard Intuitivo:** Visualização de cursos, turmas e matérias.
- **Gerenciamento de Aulas:** Cadastro, edição, exclusão e visualização de todas as aulas.
- **Conclusão de Aulas:** Permite marcar uma aula como "concluída", registrando quem a aplicou.

### 👨‍🎓 Acesso do Aluno/Professor
- **Filtro de Aulas:** Alunos e professores podem encontrar aulas por ano, curso e matéria.
- **Visualização de Detalhes:** Cada aula tem uma página com detalhes, incluindo descrição, arquivos para download e links externos.
- **Responsividade:** Design adaptável para desktops, tablets e celulares.

### 📊 Relatórios
- **Relatório de Aulas Concluídas:** Uma tabela para visualizar todas as aulas que já foram aplicadas.
- **Dashboard de Gerenciamento:** Gráficos e estatísticas sobre as aulas cadastradas.

## 🛠 Tecnologias

O projeto é construído com tecnologias modernas, focando em performance, escalabilidade e uma ótima experiência de desenvolvimento.

### Frontend
- **Framework:** [Next.js](https://nextjs.org/) (com App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Componentes UI:** [Shadcn/UI](https://ui.shadcn.com/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Formulários:** [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)

### Infraestrutura e Deploy
- **Hospedagem Frontend:** [Vercel](https://vercel.com/)
- **Hospedagem Backend (API):** [Render](https://render.com/)
- **Controle de Versão:** Git & GitHub

## 🚀 Instalação

Para rodar este projeto localmente, siga os passos abaixo:

### Pré-requisitos
- Node.js (v18 ou superior)
- npm, yarn ou pnpm

### Configuração

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Masterbarreto/Front_Aulas.git
   ```

2. **Navegue até o diretório do projeto:**
   ```bash
   cd Front_Aulas
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

---

## 📖 Uso

Após a instalação, você pode iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver a aplicação em funcionamento. A aplicação irá redirecionar para a tela de dashboard, onde a navegação principal começa.
