# SubAulas

SubAulas é uma aplicação web desenvolvida para a EEEP Walter de Sá Cavalcante, com o objetivo de gerenciar e disponibilizar aulas de substituição para os alunos. A plataforma permite que os professores façam o upload de materiais de aula, que podem ser acessados pelos alunos de diferentes cursos e turmas.

## Features

- **Login de Professor:** Acesso seguro para professores gerenciarem as aulas.
- **Dashboard Intuitivo:** Visualização de cursos, turmas e matérias.
- **Upload de Aulas:** Ferramenta para upload de arquivos e links de aulas.
- **Gerenciamento de Aulas:** Edição, exclusão e visualização de todas as aulas cadastradas.
- **Filtro de Aulas:** Alunos podem encontrar aulas por ano, curso e matéria.
- **Visualização de Detalhes:** Cada aula tem uma página com detalhes, incluindo descrição, arquivos e links.
- **Responsividade:** Design adaptável para desktops, tablets e celulares.

## Instalação

Para rodar este projeto localmente, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Masterbarreto/Front_Aulas.git
   ```

2. **Navegue até o diretório do projeto:**
   ```bash
   cd Front_Aulas
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   # ou
   # yarn install
   ```

## Uso

Após a instalação, você pode iniciar o servidor de desenvolvimento:

```bash
npm run dev
# ou
# yarn dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver a aplicação em funcionamento.
