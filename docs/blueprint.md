# **App Name**: SubstituteMe

## Core Features:

- Request Initiation: Teachers can initiate new substitution requests by selecting the class, date, time, and reason.
- Request Status View: Teachers can view the status of their pending substitution requests.
- Substitution History: Teachers can review a history of their past substitutions.
- Intelligent Suggestion: When a request is created, use a tool to provide teachers with an AI-powered list of colleagues best suited to provide cover, based on factors such as subject matter expertise and availability.

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF) for a professional and trustworthy feel.
- Background color: Light gray (#F0F0F0) to maintain a clean and professional aesthetic.
- Accent color: Steel blue (#4682B4) for interactive elements and highlights.
- Body and headline font: 'Inter', a sans-serif font that is modern and readable.
- Use flat, minimalist icons in steel blue (#4682B4) to represent actions and status.
- Use a clean, well-organized layout with ample whitespace to avoid clutter.
- Incorporate subtle transitions and animations to provide feedback on user actions.
